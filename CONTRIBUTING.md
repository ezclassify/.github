# Contributing to EzClassify

The full contribution process is in the
[project-wide guide](https://github.com/ezclassify/ezclassify/blob/main/CONTRIBUTING.md).
It covers which repository to change, the contribution loop, and what a good
change looks like. If the repository you are working in has its own
CONTRIBUTING file, read that one for its toolchain and conventions.

## Sign your commits

**Pending counsel review. This section records the intended contribution process
and is not a legal conclusion.**

Contributions are accepted under the Developer Certificate of Origin 1.1. There
is no separate agreement to sign and nothing to send us. You certify the
statement by adding a `Signed-off-by` line to each commit, and `git commit -s`
writes that line for you from your git configuration.

The full text is in the
[DCO](https://github.com/ezclassify/ezclassify/blob/main/DCO.md). It is the single
text for every public EzClassify repository, and each of them follows the same
process.

## Issues

Every EzClassify product shares one tracker:
[open an issue](https://github.com/ezclassify/ezclassify/issues/new/choose) and
pick the app you are using. Open one before starting a non-trivial change, so
the approach is agreed before you put in the work.

Report security vulnerabilities privately. See the
[security policy](SECURITY.md).

## Code of Conduct

This project follows our [Code of Conduct](CODE_OF_CONDUCT.md). By
participating, you are expected to uphold it.
