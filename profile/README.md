# <img src="icon.svg" alt="" width="32"> EzClassify

Security marking software for applications and document workflows.

**Start at [ezclassify/ezclassify](https://github.com/ezclassify/ezclassify).** It covers the product, the public repositories, how to try an integration, and how to report a bug.

- [Report a bug or request a feature](https://github.com/ezclassify/ezclassify/issues/new/choose). Never post classified information, CUI, real marked documents, credentials, or customer data.
- [Report a security vulnerability](https://github.com/ezclassify/ezclassify/blob/main/SECURITY.md) privately.
- [ezclassify.com](https://ezclassify.com) for the product and contact.
