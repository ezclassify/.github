# Security Policy

Do not open a public issue for a security vulnerability.

Email **security@ezclassify.com**. That address covers every EzClassify
repository and every EzClassify application, so use it whether you found the
issue in a client library, a public marking scheme, the REST API, or Studio.
Include:

- What is affected: the repository, package, application, and version.
- A description of the issue and its impact.
- Steps to reproduce, with a proof of concept if you have one.
- Any suggested remediation.

The [central security policy](https://github.com/ezclassify/ezclassify/blob/main/SECURITY.md)
describes the scope, what counts as a vulnerability, and how reports are
handled. A repository with its own SECURITY.md follows that file instead.
