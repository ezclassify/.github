# Support

## Getting help

Every EzClassify app and repository shares one issue tracker:
[ezclassify/ezclassify](https://github.com/ezclassify/ezclassify). Open an
issue there and choose a form: a bug in a deployed app (Studio, the REST API,
MCP server, CLI, SSO, or an installation), a bug in a library, UI component or
the website, a feature request, or a documentation problem. Then pick the app
you are using under "What are you using?". Pick "Not sure" if you
cannot tell. Search the
[existing issues](https://github.com/ezclassify/ezclassify/issues) first, and
include the version and steps to reproduce.

The tracker is public. Never post classified information, CUI, real marked
documents, credentials, tokens, or customer data. Use synthetic examples
instead.

## If you cannot post publicly

Customers working from an air-gapped site, or under a support contract, can
email [support@ezclassify.com](mailto:support@ezclassify.com) or use the
[contact form](https://ezclassify.com/contact).

## Security vulnerabilities

Do not open a public issue. See the [security policy](SECURITY.md).
